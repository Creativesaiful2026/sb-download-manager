# SB Download Manager
ব্রাউজার + ডাউনলোডার + ক্লিপবোর্ড মনিটর।
নতুন ভার্সন: GitHub-এ Releases > Draft new release > tag দিন (যেমন v1.0.1) > Publish।
২-৩ মিনিটে Actions APK বানিয়ে Release-এ যুক্ত করবে, অ্যাপ নিজে আপডেট দেখাবে।

## ভিডিও ডাউনলোডার (yt-dlp)
মেনু > "ভিডিও ডাউনলোডার"। রেজুলেশন বেছে নিন, নোটিফিকেশনে প্রগ্রেস দেখুন।
ফাইল সেভ হয় Downloads/SB Download Manager ফোল্ডারে। কাজ না করলে "ইঞ্জিন আপডেট" চাপুন।
